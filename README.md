# 方程式ステップ (Equation Steps)

ゲーム感覚で数学を学ぶコンセプトシリーズ。中学1年『数と式』の方程式を、解き方の手順を選んで覚えるゲームです。

方程式が表示され、『次の一手』を3つの選択肢から選びます。
移項では、項が＝を飛び越えて符号が反転するアニメーションを見せます。
ダミーの選択肢は典型ミス（符号を変え忘れる、片辺だけ割る、一部の項にしかかけない）で、選ぶと理由が一言出ます。

- ステージ1： 基本の移項
- ステージ2： かっこ・小数
- ステージ3： 分数（両辺に最小公倍数をかける）
- ステージ4： 比例式（ad = bc）
- ステージ5： 解から定数を求める

問題は、解を元の方程式に代入する検算を通ったものだけを自動生成しています。
